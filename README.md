# 造世界创作地图

基于 Next.js 的静态学习路线原型。用户分步回答能力、目标、策划状态和工作方式，右侧生成可调整的学习清单；下方可浏览三条互斥路线和朋辈课程。

```bash
npm install
npm run dev
```

访问 http://localhost:3000。运行 `npm run build` 可生成静态站点至 `out/`。课程和路线数据维护在 `app/data.js`；部分课程链接指向朋辈课程总表附件位置，CLI 教程待核实。问卷答案仅保存在当前页面内，不上传。

问卷答案、追问状态与进度保存在当前浏览器的 localStorage 中（键名 `world-learning:v2`）；点击“重新开始”会重置。数据不会上传，也不会跨浏览器同步。官方指南集中在 `/official/`。清单按所选主路线展示，选修从对应任务旁分出。
